# Travel Fi — Реестр технических долгов

> **Назначение:** живой реестр известных технических долгов и нефункциональных пробелов. У каждого долга — `id` (`D-*`), приоритет, секция-владелец и (где уместно) ссылка на мильстоун, который его закрывает.
> **Приоритеты:** `🔴 Высокий` (блокирует/сильно тормозит работу) · `🟠 Средний` (стоит сделать в ближайшее время) · `🟡 Низкий` (приятно иметь).
> **Жизненный цикл статуса:** `Open` → `In progress` → `Closed`. При закрытии — перенести строку в «Закрытые» и указать *когда/почему* (`git log` по коммиту).
> **Связанные документы:** статус → [`docs/ROADMAP_ru.md`](docs/ROADMAP_ru.md); грант-оценка → [`docs/MILESTONES_ru.md`](docs/MILESTONES_ru.md); инструкции для ИИ-агента → `.roo/rules/*`; архитектура → [`docs/README_ru.md`](docs/README_ru.md).
